# 大白萝卜 / Ordis 🥕

化工工艺工程师 · 独立开发者  
把流程模拟、CAPE-OPEN 和工程工具做成可用的软件。

外操 → 工艺研发 → 软件开发；喜欢化工，也喜欢写代码。

## 现在

- **RadishFlow** — Rust + .NET 10 的可扩展流程模拟平台，CAPE-OPEN 适配，2026-09 恢复迭代
- **Radish** — 面向兴趣与创作者群体的社区，Web 已发布，Flutter 客户端推进中
- **RadishAxiom** — 面向 AI Agent 的验证优先语言与可信语义层
